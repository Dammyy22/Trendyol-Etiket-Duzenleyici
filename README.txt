TRENDYOL ETIKET DUZENLEYICI - WINDOWS
=====================================

Uygulama ne yapar?
- Trendyol'un A4 PDF etiketlerini otomatik bulur.
- Gereksiz boşlukları kaldırır.
- Etiketleri 58 mm termal yazıcıya uygun 384 piksel genişliğinde hazırlar.
- Etiketleri alt alta dizer ve JPG dosyalarına böler.
- Barkodları yeniden üretmez; doğrudan PDF'den yüksek kalitede alır.

KULLANIM
1. Trendyol_Etiket_Duzenleyici.exe dosyasına çift tıklayın.
2. "PDF Seç" düğmesiyle Trendyol PDF'sini seçin.
3. Bir JPG'de bulunacak etiket sayısını seçin. Önerilen değer: 5.
4. "JPG'leri Hazırla" düğmesine basın.
5. PDF'nin yanındaki "..._jpg_etiketler" klasöründen JPG'leri alın.

Not:
- İlk sürüm Trendyol'un 3 sütun x 3 satırlı A4 etiket formatına göre hazırlanmıştır.
- Önerilen çıktı ayarı: 5 etiket / JPG.
